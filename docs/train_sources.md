# 学習用の資料（ColQwen2.5 の追加学習）

[train_sources.csv](train_sources.csv) は、方式 C のモデルを追加学習するための決算説明資料の一覧です（2026-11-01 作成）。評価セットの資料（[sources.csv](sources.csv)）とは別に置いています。PDF は `data/train/raw/` に保存し、再配布しません。

## 会社の選び方

- **評価セットの15社は使わない。** 決算説明資料は、同じ会社なら期が違ってもレイアウトがほとんど同じです。そのため、評価に使った会社の資料で学習すると、実質的なデータリークになります。この条件は `scripts/download_sources.py --split train` と `scripts/finetune_colqwen.py` でも確かめていて、会社 ID か会社名が一致すれば止まります。
- 評価セットと同じ5業種から、各業種3社を目標に選びました。
- 各社2冊です。2026年3月期の通期決算と、2027年3月期の第1四半期決算です。12月決算の中外製薬は、2025年12月期の通期決算と、2026年12月期の第2四半期決算を使います。

## 利用規約の基準

各社の IR サイトの利用規約と robots.txt を確認して、次の基準で判断しました。判断の要旨は CSV の `terms_summary` 列にあります。

- **使う**：個人的・非商業的な利用やダウンロードを明示的に認めている会社。または、規約が「著作権は当社に帰属」「法律で認められる範囲を超える利用には許可が必要」とだけ書いていて、複製を一律には禁じていない会社。後者は、私的使用（著作権法30条）と情報解析（30条の4）の範囲として扱います。
- **使わない**：規約が無断の複製・転用・使用を、個人利用の例外なしに禁じている会社。PDF の置き場所の robots.txt がアクセスを拒否している会社。投資家かどうかを確認する画面がある会社。スクリプトからの取得が拒否される（403）会社。拒否された場合も、回避はしません。

| エーザイ | IR ページに投資家かどうかを確認する画面がある |
| ソニーグループ、パナソニックHD、デンソー | サイトがスクリプトからのアクセスを拒否する（403） |

調査の途中で、アステラス、日立、三菱電機が代わりの候補として挙がりましたが、どれも評価セットの会社なので外しました。

## 結果

### v1（最初の追加学習、[configs/finetune_c.toml](../configs/finetune_c.toml)）

11社・22冊、858ページを使います。

| 業種 | 会社 |
|---|---|
| 製造業 | ホンダ、ダイキン工業、小松製作所 |
| IT・通信 | NTT、NTTデータグループ |
| 金融 | 三井住友トラストグループ |
| 医薬 | 中外製薬、塩野義製薬 |
| 商社・不動産 | 三井物産、住友商事、三菱地所 |

金融とIT・通信は、規約と取得の条件を満たす会社が少なく、評価セットより社数が少なくなりました。医薬は、取り込めなかった1社を外して2社です。

### v2（データを増やした追加学習、[configs/finetune_c_v2.toml](../configs/finetune_c_v2.toml)）

2026-11-02 に、同じ基準で12社を追加しました。v1 の11社と合わせて23社・46冊、1,892ページです。v1 で少なかった金融・IT・通信・医薬を優先して探しました。

| 業種 | 追加した会社 |
|---|---|
| 製造業 | 富士フイルムHD、島津製作所 |
| IT・通信 | 野村総合研究所、BIPROGY、日鉄ソリューションズ、インターネットイニシアティブ |
| 金融 | かんぽ生命保険、SBIホールディングス |
| 医薬 | 日本新薬、参天製薬、ツムラ |
| 商社・不動産 | 豊田通商 |

金融は、規約か取得の条件で外れる会社が多く、2社にとどまりました。SBIホールディングスは通期の資料が159ページあり、追加したページの2割ほどを1社が占めます。v1 で使った858ページの一覧は `data/train/pages_v1.jsonl` に残してあり、v1 の設定はこちらを読みます。
